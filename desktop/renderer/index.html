Toymate Harvest

Pre-warm Cloudflare clearance and checkout reCAPTCHA on sticky proxies so Autocheckout skips ~75s of CapSolver on the critical path. Sessions are single-use and IP-bound — the same proxy that harvested must run the checkout.

How to use

  1. Settings → paste your CapSolver API key → save.
  2. Proxies → create a group of sticky AU ISP/residential lines (session- style).
  3. Pick that group below, set how many CF sessions to keep ready (2–4 is a good start).
  4. Leave Solve spam reCAPTCHA on so each session also banks a checkout spam token (~2 min TTL).
  5. Click Start harvest before a drop (engine starts with CapSolver if needed).
  6. When the bank shows ready sessions, run Toymate → Autocheckout tasks — each run auto-claims one session and stays on that sticky proxy.
  7. Point the task at the same proxy group you harvested with (or leave it; claim overrides to the harvested exit).

CF clearance lasts ~25 min · spam tokens ~100s. Empty bank = checkout falls back to on-demand CapSolver (slower, still works). CapSolver spend scales with desired count × refill — start small. Stop harvest when you are done so CapSolver does not keep spending.

Bandai F5 Harvest

Pre-warm Playwright F5 login bridges on sticky AU ISP/resi proxies so Bandai Autocheckout skips Chromium launch on the drop path (~7–15s). Bridges are single-use and IP-bound — the same exit that harvested must run checkout.

How to use

  1. Start the engine.
  2. Pick the same sticky proxy group your Bandai tasks will use.
  3. Set desired slots (start with 1–2 — each holds a Chromium).
  4. Click Start harvest a few minutes before the drop.
  5. Run Bandai → Autocheckout — each run auto-claims one bridge when ready.
  6. Stop harvest after the drop so Chromium stops burning CPU.

Idle TTL ~6 min (executor refreshes while armed). Empty bank = normal cold checkout (unchanged). Sensors and GE risk tokens are never banked — only the warm login page. Uses local CPU only (no CapSolver bill).
